二、服务内容

班主任管家为班主任提供本地班级管理工作台，全部核心功能在设备本地完成，不依赖网络。

  • 班级与学生管理：手动新增学生，或通过 CSV/Excel 文件导入学生名单并批量建档。
  • 考勤管理：发起点名、记录迟到/请假等异常、完成考勤统计。
  • 课堂点评与事件时间线：记录学生表现，自动生成统一时间线便于回查。
  • 作业记录与完成情况跟踪。
  • 班级三视图：座位表、名单、小组视图共享同一份数据。
  • 统计汇总：学生时间线、班级统计和周总结自动聚合。
  • 数据备份与恢复：创建本地备份文件，用于换机或数据恢复。
  • 隐私保护：应用锁（生物识别验证机主身份）与后台隐私遮罩（切后台隐藏应用预览）。

2. Service Content

Class Teacher Workbench provides a local classroom management workbench for head teachers. All core features run locally on the device and do not require a network connection.

  • Class and student management: add students manually, or import rosters in bulk from CSV/Excel files.
  • Attendance management: start roll calls, record exceptions such as lateness or leave, and complete attendance statistics.
  • Classroom comments and an event timeline: record student performance and automatically build a unified timeline for review.
  • Homework records and completion tracking.
  • Three class views: seating chart, roster, and group views share the same data.
  • Statistics: student timelines, class statistics, and weekly summaries aggregate automatically.
  • Data backup and restore: create local backup files for device migration or data recovery.
  • Privacy protection: app lock (biometric owner verification) and a background privacy shield (hides the app preview in the recent-tasks screen).
